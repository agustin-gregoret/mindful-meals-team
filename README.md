# Nourishly Connect

Build a modern nutritional tracking web app with role-based access for nutritionists and patients (mobile-first interface for patients, responsive desktop/mobile dashboard for nutritionists).

Key features:
1. Patient portal (mobile-first):
   - Daily structured meal logger (date, time, meal type: breakfast, lunch, snack, dinner; foods, portions/quantities, notes/feelings).
   - Daily meal timeline and progress view with feedback badges.
   - Section to view nutritionist comments/recommendations on their logs.
   - Educational content library (articles, healthy habits, nutrition tips).
   - Upcoming consultations view and request/booking form for initial or follow-up consultations.

2. Nutritionist dashboard:
   - Patient management overview (list of active patients, quick status, recent meal logs).
   - Detailed patient profile view: full meal log history, timeline filter, ability to add inline comments and feedback on meal entries.
   - Consultation manager to view bookings, schedule sessions, and mark payment status (coordinated manually/offline).
   - Content management to publish educational articles and nutritional guides for patients.

3. Role switcher or toggle for easy demonstration and testing between patient and nutritionist views.
4. Clean, fresh, and professional health-focused aesthetic (wellness greens, warm neutrals, clear typography).
